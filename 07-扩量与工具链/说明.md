# 07 扩量与工具链

## 解决什么

把"能抓到"变成"抓得又多又快"。这一类的定位是**武器库**，不是方法论：告诉你现在有哪些客户端能过指纹、哪些入口能多拿一倍数据、哪些兜底源能在站点删数据后仍然捞到。方法论在 01/02/03/06，工具选型与扩面清单在这。

## 三个子类

| 子类 | 一句话 | 内容 |
|---|---|---|
| `01-客户端与指纹工具` | 用哪个客户端，怎么让它不像爬虫 | curl_cffi / hrequests / Scrapling / camoufox / patchright / nodriver / undetected-chromedriver / tls-client / 打码平台 / 代理池 |
| `02-采集面扩展` | 同一个站怎么多拿 10 倍数据 | Sitemap 递归 / ID 爆破 / 时间切片 / 排序切片 / 关键词枚举 / 关联图遍历 / 站点变体 / 存档兜底 |
| `03-资产面扩张` | 一个域名怎么长出整个数据面 | CT 日志 / Wayback / CommonCrawl / ASN 反查 / dork / 子域 / 存储桶；含 `harvest.py`、`jsmine.py` 两个可运行工具 |

## 何时进这一类

- 已经能抓到，但量不够（3 万 vs 50 万）。
- 想少写代码：直接换一个自带指纹伪装的客户端。
- 被封了想找现成的反检测方案。
- 站点删了数据/关站，想从别处捞回来。

## 类内先后

先 `03-资产面扩张`（横向：到底有几个站、几个子域、几份历史快照）→ `02-采集面扩展`（纵向：单站怎么把量吃满）→ `01-客户端与指纹工具`（用什么客户端把入口全打通）。顺序反了会选完工具才发现入口只覆盖了 10% 的数据。

## 不该在这里解决

- 要不要抓、从哪进最便宜 —— `01-决策与准入`。
- 参数加密 / sign 生成 —— `08-请求层逆向与签名`（入口先走 `03-03`）。
- 被抓了但抓不深 —— `03-反爬对抗与逆向/05-深度与反爬`。
- 解析与入库 —— `05-解析与数据`。
- 速率与并发计算 —— `06-工程化与运行/02-速率与范围`。

## 与主线的接法

```
01 准入速判（选出入口）
        ↓
07-03 资产面（站外还有哪些入口）→ 07-02 采集面（站内怎么吃满）
        ↓
07-01 选客户端（把每个入口打通）→ 06-02 速率（把量顶到封禁线）
        ↓
05 解析 → 06-03 缓存与复用 → 06-04 管道归档（断了能续、只抓新增）
```

## 内容速览

- 工具选型的第一原则：**能用 HTTP 客户端解决的，绝不开浏览器**；开浏览器是 30 倍内存换 2 倍成功率。
- 扩面的第一原则：**列表页只能拿到冰山一角**，Sitemap + ID 空间 + 时间切片三件套至少 ×5。
- 兜底源不是"备用"，是常规手段：Wayback 与 Common Crawl 能捞到站点已经删掉的页面。
